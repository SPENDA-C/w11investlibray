# LP 制作ブリーフ

公開 LP（先行登録ページ）をデザインする人向けの仕様。
**コードを読まずにここだけで判断できる**ことを目指している。

実物は `npm run dev` → `http://localhost:8787/lp`。

---

## 何のためのページか

| | |
|---|---|
| サイト名 | ゴールデンクロスーインカムゲインを究める資産運用（ヘッダーは短縮名「ゴールデンクロス」） |
| 目的 | 先行登録（メールアドレスの取得）1 つだけ |
| 読み手 | 個人投資家。株式スクリーナーを使ったことがある層 |
| 置き場所 | 独自ドメインの `/`（公開）。ダッシュボードは別サブドメインで Access の後ろ |
| **出してはいけないもの** | **銘柄名・価格・スコア・ランキングなど市場データを一切載せない** |

最後の 1 行は見た目の都合ではなく、市場データの提供元との取り決めが
未確認だという事情による（`DATA-SOURCES.md`）。
実データのスクリーンショットも同じ理由で置けない。

## 書いてはいけない表現

金融商品取引法と景品表示法の両方に触れうるので、**表現は見た目より優先する。**

| 禁止 | 代わりに |
|---|---|
| 儲かる / 稼げる / 勝てる | （書かない） |
| 推奨銘柄 / おすすめ銘柄 | 条件に合致した候補 |
| 予測 / 予想（株価について） | 条件への合致度 |
| 必ず / 確実に / 高確率で | （書かない） |
| スコア = 期待リターン | スコアは条件への合致度であって、何 % 上がるかを表す数字ではない |

**「AI が銘柄を当てる」と読める表現にしない。** AI の役割はニュースの
分類・要約・説明に限る、というのがこのシステムの設計そのもの。

## フォームの仕様

| 項目 | |
|---|---|
| `email` | `type="email"`、`required`、最大 254 文字 |
| `consent` | チェックボックス、`required`。同意した時刻を保存する |

## 見た目の決まり

デザインの出どころは `spenda-agency/landing-page` の `googletool-orange-basic`。

| | |
|---|---|
| 配色 | `packages/worker/src/ui/tokens.ts` が唯一の定義。LP は `BRAND`（`--brand-*`）だけを使う |
| 明暗 | **LP は明暗で変わらない**（`color-scheme: light`）。ダッシュボードは両対応 |
| 本文幅 | `.container` = `--maxw`（1200px）＋左右 20px |
| 節の余白 | `.band` = 上下 60px（狭い画面で 45px） |
| ボタン | `padding: 12px 28px` / 16px / 700 / `border-radius: 6px` |
| 見出し | `.section-title` 28px、`.hero-title` 36px（狭い画面で 22 / 27px） |
| カードの影 | `--brand-shadow-1/2/3` の 3 段階しか使わない |
| タップ領域 | **最小 44px**。入力欄とボタンは 50px |
| 書体 | Noto Sans JP（Google Fonts）。`LP_FONT_STACK` が先頭に置いている |
| アイコン | **インライン SVG**（`lp.ts` の末尾）。Font Awesome は読み込まない |
| 画像 | 現在ゼロ。足すなら Worker のバンドルに載るサイズか、R2 配信かを決める |
| 画面幅の切れ目 | 1023px / 767px / 480px |

**なぜ LP だけダークモードを持たないか。** ヒーロー下の波は白で塗った SVG で、
カードは白地に影を落としている。暗い地に置くとどちらも破綻する。
LP は名刺なので、どの環境でも同じ色で出す。

## CSP（コンテンツセキュリティポリシー）の制約

`src/headers.ts` が全ページに CSP を掛けている。デザイン上、次の 2 つが効く。

- **JavaScript は使えない。** `script-src 'none'`。**これは LP でも同じ。**
  スクリプトが要る演出を入れるなら、まず `headers.ts` と
  `test/headers.test.mjs` を直す必要がある（意図的に固い作りにしてある）
- **外部ホストは Google Fonts の 2 つだけ。** LP には `LP_CSP` を掛けていて、
  既定の `CSP` との差は `style-src` の `https://fonts.googleapis.com` と
  `font-src` の `https://fonts.gstatic.com` だけ。**この差はテストで固定してある**
  ので、解析タグや外部の画像を足すと `npm test` が落ちる
- ダッシュボード側（Access の内側）には外部ホストを 1 つも足さない

インラインの `<style>` と `<svg>` 要素、`data:` の画像は許可済み。

### JavaScript 無しでテンプレートの挙動を再現している箇所

元のテンプレートは 5 つの演出を JS でやっている。CSP を維持するため、
すべて CSS とブラウザの機能に置き換えてある。**JS で書き直さないこと。**

| 元の実装 | 置き換え | 非対応ブラウザ |
|---|---|---|
| ヘッダーの背景切替（`scroll` イベント） | `animation-timeline: scroll()` | 常時白いヘッダー |
| FAQ のアコーディオン | `<details>` / `<summary>` | ブラウザ標準で動く |
| スクロールのフェード | `animation-timeline: view()` | 最初から表示 |
| Back to Top の出し入れ | `#top` へのアンカー（常時表示） | 同じ |
| モバイルメニュー | **置いていない。** 狭い画面ではフッターの一覧が担う | 同じ |

`animation-timeline` は `@supports` と `prefers-reduced-motion` で二重に
囲ってある。効かない環境では**演出が無いだけで、読めなくなる壊れ方はしない。**

> ヘッダーの背景と文字色は **keyframes を 2 本に分けている**。
> 1 本にまとめて `.brand` にも掛けると、文字の後ろに白い箱が出る。

## テンプレートを当てるときに触るファイル

| ファイル | 何を差し替えるか |
|---|---|
| `packages/worker/src/ui/tokens.ts` の `BRAND` | LP のブランド色 |
| `packages/worker/src/ui/tokens.ts` の `TOKENS` | 共有パレット。**アプリ側にも反映される** |
| `packages/worker/src/ui/lp.ts` の `STYLES` | LP のレイアウトと装飾 |
| `packages/worker/src/ui/lp.ts` の各節 | マークアップ。**本文（コピー）はそのまま流用できる** |

`tokens.ts` 以外の場所でパレットを再定義すると `npm test` が落ちる
（`test/tokens.test.mjs`）。LP とダッシュボードで色がずれるのを防ぐため。

## 確認の手順

```bash
npm test                    # 表現と構造の検査を含む
npm run dev                 # /lp を開く
```

テストが検査していること（デザイン変更で壊しやすい順）:

- 免責が出ている
- 銘柄名・価格・`BUY_NOW` が LP に出ていない
- ハニーポットが画面外に置かれている
- 同意なしでは登録できない
- **LP が外へ出るのは Google Fonts の 2 ホストだけ**
- **LP に `<script>` が 1 つも無い**
- FAQ が `<details>` のまま（JS 無しで開閉できる）
- ブランド色を `tokens.ts` 以外で定義していない
- LP が `color-scheme: light` のまま

描画は**デスクトップ・モバイル・ダークの 3 つで必ず見ること。**
これまでにこの確認で拾った不具合:

- 見出しだけ左端に寄る（`margin` の一括指定が `margin-inline: auto` を打ち消していた）
- 日本語の文中に余分な空白が入る（ソースの改行がそのまま空白になる。**1 文は 1 行に書く**）
- ヘッダーの文字の後ろに白い箱が出る（背景と文字色を 1 本の keyframes にまとめていた）
